# Website LibraryReg

Website perpustakaan yang dibuat dengan HTML, CSS, dan JS. Proyek ini menampilkan informasi perpustakaan, menu navigasi yang terstruktur, formulir pendaftaran anggota secara online, dan halaman pengelolaan data anggota untuk petugas perpustakaan.

## 📌 Gambaran Umum

Project ini dibuat sebagai landing page sekolah berbasis multi-page sederhana. Website ini terdiri dari beberapa halaman utama yang menampilkan informasi umum perpustakaan, formulir pendaftaran, serta data anggota.

### Fitur Utama

- **Beranda:** Hero section, profil perpustakaan, layanan perputakaan.
- **Pendaftaran:** Form pendaftaran anggota perpustakaan.
- **Data Anggota:** List anggota perpustakaan yang berhasil terdaftar.
- **Footer:** Informasi jam pelayanan & kontak (telepon dan email).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur halaman menggunakan elemen semantik seperti `header`, `main`, `section`, dan `footer`.
- **CSS3:** Styling responsif, layout flexbox, tipografi, spacing.
- **JavaScript**
